# 🐉 RolemIAster へようこそ！

サイコロ（またはマウス）を手に取り、想像力の歪みだけが限界となる冒険に備えよう！ **RolemIAster** は、AIによって駆動される無限のRPGで、あなた自身の物語のヒーロー（または悪役）になることができます。

---

## ⚠️ 法的免責事項（退屈だけど必要な部分）

**読まないとサイコロの怒りを買うぞ：**

1.  **🤖 内蔵ローカルAI:** RolemIAsterは独自のデジタル脳を搭載しています。**インターネット接続なし**で、変な操作なしで動作します。インストールしてプレイ！
2.  **☁️ オプションのクラウド:** 外部AI（OpenAI、Geminiなど）にお金をかけたいなら、クレジットカードでどうぞ。費用は自己責任です。
3.  **🎲 ジェネレーティブカオス:** AIは物語をその場で作り出します。語り手が狂って牛が降ってくると言っても、私たちを見ないでください。開発者はモデルが生成する狂気に対して責任を負いません。
4.  **🏗️ アーリーアクセス:** これは工事中です。バグを見つけても、それは欠陥ではなく「驚きの機能」です！（フィードバックをくれると、とても助かります。）

## 🖥️ システム要件とデジタルブレイン（AI）

RolemIAsterは**ローカルAI**で動作します。つまり、PCが思考の重労働を行います。インターネットは不要ですが、恐竜時代のものではないグラフィックカードが必要です。（注：部屋が寒い場合、このゲームは無料の暖房として機能します。）

### ⚙️ 初心者向けコンセプト

**VRAM（ビデオメモリ）**はAIのガソリンです。
*   **TurboQuant**のおかげで、RolemIAsterは現在、グラフィックカードをクラッシュさせることなく、**100,000語（トークン）以上**を記憶できます。これは以前のほぼ3倍です。
*   GPUのメモリが不足すると、ゲームは喘息を持つカタツムリよりも遅くなります。

### 🚨 助けて！PCが遅い！（VRAMの問題）

ゲームの応答がWhatsAppの返信より遅い場合、おそらくVRAMが不足しています。

**調子に乗りすぎた場合の症状：**
1.  **モデルがRAMにスワップされる:** PCはグラフィックではなく通常のメモリを使用します。結果：極端な遅延。
2.  **軽度のオーバーフロー（1〜2GB）:** 応答ごとに30〜60秒かかります。
3.  **中程度のオーバーフロー（3〜5GB）:** 2〜5分。コーヒーを買いに行けます。
4.  **重度のオーバーフロー:** 10〜30分。プレイ不可。

#### 🛡️ 緊急プロトコル
うまくいかない場合は、次の手順を順番に実行してください：

1.  **📉 VRAMの割合を下げる:** 設定に移動し、**85%**に下げてください。再起動して試してください。
2.  **🧹 クリーンアップ:** 40個のタブが開いているブラウザを閉じてください。それらがメモリを食い尽くしています。
3.  **🛑 70%の制限:** **70%**の割り当てVRAMを下回らないでください。
    *   *なぜ？* AIは「思考」のためにスペース（KVキャッシュ）を必要とします。70%未満を与えると、AIは空白になりエラーが発生します。
4.  **🔙 戦術的撤退:** 何もうまくいかない場合は、より小さなモデルにダウングレードしてください（9Bから4Bへ、または4Bから2Bへ）。

### 🌍 プレイ方法（マルチバースとあなた）

ゲームを開くと、2つの道があります：

1.  **🆕 新しい冒険:** ゼロから伝説を創造しましょう。ゲームは**名前、職業、身体的特徴、心理的特徴、そしてあなたの物語の背景/設定**を尋ねます。さらに、キャンペーンを導く**難易度**と**ユーモアのトーン**を選択します。
2.  **💾 ゲームの続行:** RolemIAsterは**リアルタイムで保存**されます。ここでは「死ぬ前にロードする」や後戻りはできません。すべての決定、すべてのミス、すべての傷は物語に刻み込まれます。これは**挑戦**です：あなたがしたことは、されたことです。その結果と共に生きよ…またはそれと共に死ね。

RolemIAsterは独立したゲームではありません。これは**永続的なマルチバース**です。
*   **無限の世界:** 独自のロアを持つ独自のユニバース（**中世ファンタジー**または**サイバーパンク**）を作成します。
*   **無限のキャラクター:** 各世界内で、好きなだけ多くのヒーローを持つことができます。
*   **共有タイムライン:** 注意！あるキャラクターが行ったことは、他のキャラクターの世界に影響を与えます。AIはあなたの他のヒーローを認識し、世界の住民として認識します。
*   **「感覚」を持つAI（スーパーRAG）:** RAG（Retrieval-Augmented Generation）システムはAIの「スパイ」として機能し、世界、誰が同行しているか、どこにいるか、そして何が起こったかについての記憶を提供し、物語を100％一貫したものにします。

## 📜 ゲームルール（はい、ルールがあります）

RolemIAsterは、古典的で堅牢なd100（100面ダイス）システムを使用しています。

### 1. あなたの属性（あなたを定義するもの）
AIは、入力したコンテキスト、職業、説明に基づいてあなたの属性を生成します。生成された後、**10の追加ポイント**を自由に割り当てることができます。
*   **段階的なコスト:** 属性を14まで上げるには1ポイント。15から16は2ポイント。17以上は3ポイント！筋肉をどこに置くかよく考えてください。

*   💪 **筋力（STR）:** 純粋な物理的パワー。近接ダメージと積載量に影響します。
*   ❤️ **耐久力（CON）:** あなたの抵抗力。打撃、病気、毒に耐えるため。
*   🐘 **体格（SIZ）:** あなたの大きさ。大きく重いか、小さくすばしっこいか。
*   🏃 **敏捷力（DEX）:** 器用さ、照準、そして自分の足につまずかないこと。
*   🧠 **知性（INT）:** 学習、記憶、パズル解決。
*   🔮 **精神力（POW）:** あなたの魂、運、意志力、そして魔法の源。
*   😎 **カリスマ（APP）:** リーダーシップ、魅力、そして人を騙す（または誘惑する）能力。

### 2. クイック計算（派生能力）
エンジンは、あなたの属性に基づいてこれらの数値を自動的に計算します：

*   🩸 **ヒットポイント（HP）:** `CON * 10`。0になったら…まあ、お分かりでしょう。ゲームオーバー。
*   ✨ **マジックポイント（MP）:** `(POD * 10) + INT`。魔法のトリックの燃料。MPがなければ、トリックはありません。（MPのない魔法使いは、ローブを着たコスプレイヤーにすぎません。）
*   ⚡ **スタミナ（STA）:** `((CON+FUE+DES)/3)*10 + POD`。戦い、移動するためのエネルギー。
*   🧠 **人間性（HUM）:** `(CON+POD) * 5`。（サイバーパンクのみ：ケーブルに狂わされる前に、人間性がどれだけ残っているかを測定します。）
*   ⚔️ **アクションポイント（AP）:** `(INT + DES) / 2`。イニシアチブを決定します。最初に殴った者が二度殴る。

### 3. あなたのスキル
これらは基本値（例：隠密 = DEX + INT）から始まり、使用することで向上します。パーセンテージ（%）です。

### 4. アクション解決（ダイス）
危険なことを試みるとき（登る、嘘をつく、攻撃する…）、AIはロールを要求します。ゲームは目に見えない**d100**を振ります。（覚えておいてください：サイコロはあなたを憎んでいます。個人的なことです。）

*   **あなたの目標:** スキルレベル**以下**の数字を出すこと。
    *   *例:* クライミングのスキルが45%あります。
    *   30を出す：✅ **成功**。猿のように登ります。
    *   80を出す：❌ **失敗**。ぶつかります。
    *   **クリティカル:** スキルの**1/5以下**（または01）を出すこと。エピック！側転付きの素晴らしいパルクールをします。
    *   **ミス:** **99または100**。サイコロは今日があなたの番ではないと決めました。途中でズボンが落ち、顔から転びます。

## ⚔️ 戦闘（武器を取れ！）

言葉が通じなくなったら、殴り合いの時です。戦闘は**戦術的**で、**ティック**（時間）で機能します。

### 🕹️ 仕組み：
*   **ティック:** 各アクションには時間がかかります。重い武器は遅いです（多くのティックを消費します）。ダガーは速いです。
*   **あなたの速度:** アクションポイント（AP）に依存します。

### 基本アクション：
*   **🗡️ 攻撃:** 抜いたもので攻撃します。
*   **🛡️ ブロック:** 防御態勢をとります。ダメージを軽減しますが、スタミナを消費します。
*   **🏃 逃走:** 臆病者（または生き残りたい賢者）のため。
*   **🏳️ 降伏:** 勝てないとわかったら、慈悲を乞うことができます。
*   **✨ 魔法/サイバーウェア:** 火、レーザー、ハッキング…

### 💬 フリーテキストアクション（NEW!）
ボタンが気に入らない？まるで生身のマスターと話すかのように、したいことを書いてください！
*   **例:** 「ゴブリンにファイアボールを放つ」、「ルーンソードを抜く」、「自分にポーションを使う」。
*   **シーンディレクター:** 戦闘が生命を帯びます。AIは、物語を豊かにする環境イベントや反応を生成します：梁が落下する、敵が後退する、トーチが落下する。戦場はもう静的ではありません！
*   **AIが理解しない場合:** 再入力を求められます。あなたのターンは失われません！
*   **⚠️ 制限:** スロット間のアイテム移動（バックパックからの装備、弾薬の装填）は、インターフェースでの**ドラッグ＆ドロップ**で行われ、テキストではありません。

### ⚠️ 生存の黄金律
**戦う前に武器を抜く！**
戦闘中に武器を抜くには時間がかかります（ティック）。鞘に入ったまま捕まると、ぎこちなく抜こうとしている間に叩きのめされます。あるいはもっと悪いことに、装備スロットではなくバックパックに武器を入れたままにしている場合（「ちょっと待って、マンモスソードをバックパックから取り出す必要がある、どこかにあったはず…どこかで…」）🤦‍♂️
👉 装備されている武器のラベル（右パネル）を**クリック**して抜いてください。緑色に光ります。

戦闘中に武器を動かそうとすると時間がかかり（ティック）、不意打ち攻撃につながる可能性があり、ターンを失ったり、迫りくる斧に顔面を狙われたり、地面に落としたりする可能性が非常に高いです。（ADHDのキャラクターを作るのは良くなかったかもしれない）

## ✨ 魔法とサイバネティクス

あなたの世界が「中世ファンタジー」か「サイバーパンク」かに依存します：

### 🧙‍♂️ ファンタジー：エンチャント

4.  **注意:** 戦闘中にマナが枯渇すると、炎の剣は再び錆びた鉄の棒に戻ります。

### 🦾 サイバーパンク：インプラント
ズーム機能付きの目やゴリラの腕が欲しいですか？

2.  クレジットを支払います（未来では何も無料ではありません）。
3.  **人間性のコスト:** 各インプラントはあなたの魂の一部（**人間性**）を奪います。
    *   あまりにも多くをインストールすると、**サイバーサイコ**（殺人的な足付きトースター）になり、キャラクターのコントロールを失います。

## 🛒 店舗とサービス（SIS）

NPCと話して取引します。
*   **AIが提案、あなたが決定:** 商人やヒーラーと話すと、AIは彼らのサービス（修理、販売、治療）を提案しますが、「**サービスを見る**」ボタンが表示されるので、取引モードに入るかどうかを自分で決定できます。
*   **交渉:** あなたの**交易**スキル（カリスマに基づく）が価格を決定します。醜いか無愛想だと、騙されます。
*   **販売:** インベントリ内のオブジェクトを**右クリック**して店主に販売するか、店主にドラッグ＆ドロップします。

## 🎒 インベントリ管理（テトリス）

*   **重量:** 積載量の上限があります（筋力+体格）。あまりにも多くのジャンクを運ぶと、遅くなりペナルティを受けます（ディオゲネスはあなたの友人ではありません）。
*   **パネル:**
    *   **装備:** 着用しているもの。
    *   **ベルト:** 戦闘でのクイックアクセス（ここからのポーションの使用は時間がかかりません）。
    *   **バックパック:** 袋の底。
*   **スムーズな使用:** ポーションや食べ物を直接**あなたの顔**（ポートレート）にドラッグ＆ドロップすると、すぐに消費できます。コンテキストメニュー（右クリック -> 使用）も使用できます。

## 🎭 難易度とユーモア（あなたの苦しみをパーソナライズ）

開始する前に、AIは単に物語るだけでなく、あなたの好みに合わせて**世界を調整**することを覚えておいてください。これらのパラメータは、世界作成時に選択され、その世界では永続的です：

*   **🎮 難易度（AI管理）:** 単なるダメージ乗数ではありません。ゲームはAIに「おい、難易度はこれだ、それに合わせて行動しろ」と伝えます。
    *   **イージー:** 死ぬことはありません（またはほぼ不可能）、状況はより簡単で、価格は安く、敵はより無能です。AIは各シーンを論理的に処理し、あなたの道がバラ色になるようにします。
    *   **ノーマル:** 標準的なバランス。
    *   **チャレンジ:** AIは容赦なく、価格は法外になり、どんなミスも最後になる可能性があります。

*   **🃏 ユーモアのトーン:** AIがどのように話しかけてくるか、そしてどのような種類のイベントが発生するかを定義します。各モデルには「ユーモア」の概念の解釈方法がありますが、AIはあなたが選んだものに適応しようとします…あるいはしないかもしれません：
    *   **シリアス:** 叙事的で、暗く、フォーマルなナレーション。
    *   **皮肉:** AIはあなたのミスを笑い、常に皮肉を言い、皮肉なトーンを使用します。
    *   **デリラント:** 不条理に備えましょう。空飛ぶ牛、シュールな状況、そしてAIの最も歪んだ論理によって管理される完全なカオス。
