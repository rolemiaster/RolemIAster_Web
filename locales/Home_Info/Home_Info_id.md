📢 Pesan dari Pengembang (Akses Awal)
Selamat datang di RolemIAster. Sebelum Anda menyelami petualangan besar berikutnya, saya ingin mengambil satu menit untuk mengklarifikasi beberapa hal (saya janji akan singkat, dadu menunggu Anda).

Game ini dalam fase Akses Awal (Early Access).
Saya adalah pengembang tunggal —ya, hanya saya, keyboard saya, dan berminggu-minggu kopi— yang berarti saya melakukan semua yang saya bisa, tetapi terkadang saya tidak bisa menyelesaikan semuanya tepat waktu. Saya minta maaf sebelumnya jika saya terlambat memperbaiki bug yang sulit ditangkap, menerapkan fitur yang sangat Anda inginkan, atau merespons segera di Discord dan forum Steam. Saya mencoba melakukan banyak hal, tetapi saya belum memiliki tentakel ekstra.

Jika Anda datang mengharapkan produksi AAA yang mulus, saya khawatir Anda berada di tempat yang salah (untuk saat ini). Game ini berada pada tahap awal pengembangan, dan sejujurnya, hanya orang-orang pemberani yang memahami dan mendukung proyek independen semacam ini yang memiliki mental (dan kesabaran) untuk menanggungnya.

Jika Anda merasa game ini masih terlalu mentah untuk Anda, tidak ada yang akan marah jika Anda meminta pengembalian dana. Sebaliknya, saya akan senang menyambut Anda kembali di masa depan —dan Anda membayar 40 atau 60 USD ketika game ini sudah rampung dan selesai 😉—. Harga saat ini sengaja dibuat rendah agar sesuai dengan status pengembangannya saat ini. Jika ini tidak meyakinkan Anda, kita tidak perlu membahasnya lagi, kita tetap berteman.

Mengingat sifat proyek gila ini, rasa terima kasih saya tidak terbatas kepada siapa pun yang, terlepas dari kesulitan dan tantangan dalam prosesnya, memutuskan untuk tetap tinggal dan berkontribusi. Hanya dengan melaporkan bug atau menyarankan perbaikan, Anda telah membuat game ini menjadi lebih baik secara brutal dalam beberapa minggu sejak dirilis.

Itulah dorongan yang akan terus bekerja agar RolemIAster menjadi game yang dibuat khusus, terutama bagi Anda yang telah ada di sana, mempercayai proyek ini sejak hari pertama.

Terima kasih atas kesabaran, dukungan Anda, dan semoga para kritikus berpihak pada Anda!
