# Indice de docs `.agent/docs/`

Documentacion viva del repositorio web. Abrir solo el documento necesario para la tarea.

| Doc | Cuando abrirlo |
| --- | --- |
| `llm-wiki.md` | Investigacion, fuentes externas, decisiones duraderas o conocimiento acumulativo. |
| `web-publica.md` | Cambios de estructura, publicacion, rutas entre proyectos o QA de la web. |

## Convenciones

- Idioma: espanol castellano salvo contenido publico que requiera otro idioma.
- Preferir punteros a archivos y evidencia antes que copiar codigo largo.
- No duplicar `AGENTS.md`; las reglas globales viven ahi o en `.agent/rules/`.
- Si un procedimiento es reutilizable y especifico de este repo, va como skill en `.agent/skills/`.
